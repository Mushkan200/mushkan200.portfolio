# Personal Portfolio Website

This repository contains my personal portfolio website built for showcasing my web development and data analyst profile.

## Overview

The website is designed to present:
- My introduction and career focus
- Featured projects
- Skills and tools
- About section
- Contact information

It is built as a responsive static website and can be hosted easily using GitHub Pages.

## Features

- Clean single-page portfolio layout
- Responsive design for desktop and mobile
- Light and dark mode toggle
- Project cards for web development and data analysis work
- Skills grouped by domain
- About and contact sections
- Simple structure for easy customization

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive design principles

## Project Structure

```bash
.
├── index.html
└── README.md
```

## How to Use

1. Clone or download this repository.
2. Open `index.html` in your browser to preview the site.
3. Edit the content in `index.html` to add your own:
   - Name
   - Email
   - LinkedIn
   - GitHub
   - Resume link
   - Project details
   - Skills and career information

## Customization Ideas

- Add your real project screenshots
- Add resume download link
- Create separate pages for each case study
- Add animations or charts
- Connect a custom domain
